Etape 1

http://wawawoom.fr/geocaching/GC8GG1R/step1-e1531b13-e877-4c69-a71d-ac8eed4171ef/

Pour cette étape il fait trouver un login et un mot de passe.

En jouant avec le champ login on se rend compte que le login doit matcher cette regex /^[a-z.]+$/ Cela veut dire que le login ne peut contenir que des lettres minuscules et des points.

Il faut retrouver le nom de la personne qui est sur l'image à gauche (l'inventeur du javascript). Son nom est Brendan Eich. Donc on peut en déduire que le login est brendan.eich

D'ailleurs en testant ce login avec n'importe quel mot de passe, on se rend compte que le login est bon car le système le reconnait. Et ce message apparait alors :

Hello Brendan ! Good to see you again. Did you forget your password ? Check the source code.

Il faut ensuite fouiller dans le code source (comme suggéré précédemment), pour trouver le mot de passe. A la ligne 89 du code source on trouve une variable appelée _0xa510 qui qd on l'exécute dans la console javascript de Chrome donne le mot de passe en clair : MozZilLa2014!

Il suffit donc ensuite de rentrer comme identifiants :

login: brendan.eich mot de passe: MozZilLa2014!

Pour obtenir le Flag: StEp1ComPletEd_!

Ensuite on entre le flag à cette adresse: http://wawawoom.fr/geocaching/GC8GG1R/

Et on obtient l'url de l'étape suivante: http://wawawoom.fr/geocaching/GC8GG1R/step2-dc3504d9-7d66-4a9d-982b-e161b02932d5/

Etape 3

Il s'agit de cracker le mot de passe d'un fichier zip qqui contient un fichier texte dans lequel il y a le flag recherché.

Il existe des utilitaires en ligne de commande qui permettent de faire ca.

http://cvs.schmorp.de/fcrackzip/fcrackzip.html http://software.schmorp.de/pkg/fcrackzip.html

Je fournis également la regex qui compose le mot de passe. Il est composé de 7 caractères, ne contient que des lettres minuscules et des chiffres. Avec ces informations et cet utilitaire, il devient facile (mais chronophage) de brute forcer le mot de passe.

fcrackzip -b -c a1 -u -v -l 7-7 step3.zip

Le fichier texte contenu dans le Zip contien le flag: W3LL/CRACK3D!

etape 4

Il s'agit là d'une épreuve de programmation. Le principe est simple, j'affiche un QR code auquel il manque les marqueurs. Ce qui le rend illisible par un moyen standard. Le but est de scanner ce qr code, et de renvoyer le message contenu. Et tout ca en moins de 3 secondes. Autant dire que c'est à un programme de le faire, car à la main, c'est tout simplement impossible.

J'ai developpé un petit programme accessible à cette adresse qui fait ce travail : http://wawawoom.fr/geocaching/GC8GG1R/step4-4d0e43ca-56de-465b-8fac-6ce35429502f/solver-8695c0e2-2f26-480f-ad03-6a882ba88765.php

Et ce programme donne la réponse !-Qu1cK-ReSSp0nse-C0d3-!
