Bonjour,

Cette énigme est basée sur le jeu vidéo ZELDA (sur NES) et se résout en 4 grandes étapes :

=================================

1/ Trouver la page qui explique les missions:
Dans la page du listing j’ai dissimulé plusieurs liens :
- Champ Indice: https://bit.ly/2V0wT0U
- EXIF Image: https://bit.ly/2HTz0zX
- Commentaire HTML encodé en binaire: https://bit.ly/2HLmS4E (Cette page contient un MOT DE PASSE qui va servir plus tard. Il y est écrit « NONAG = ESSAPEDTOM ». Lu à l’envers on découvre MOTDEPASSE = GANON
- Lien sur l’image: http://wawawoom.fr/geocaching/GC84ZZG/nothing4-a4d7a26d-776e-49dc-9dd6-5b3e3d77dfa2
- Parametre url geocheck : https://bit.ly/2uD7ZbT
- QR CODE caché dans le bas de l’image (c’est cette page qu’il faut trouver) : http://wawawoom.fr/geocaching/GC84ZZG/step1-6a6baae3-5937-4347-83c8-eedcb61303f7

=================================

2/ Remplir la mission 1 : reconstituer la FTFORCE. Cela consiste en recomposer un Fichier ZIP divisé en 3.

1ère partie du ZIP : 
- Il faut résoudre une énigme visible ici : http://wawawoom.fr/geocaching/GC84ZZG/step2-998c776d-8d84-4756-b92f-e805a22ac773/
On y voit un genre de QRCode, mais on ne sait pas quels sont les éléments qui doivent être noir et ceux qui doivent être blanc.
L’indice « Gardez le minéral. », laisse entendre qu’il faut garder (en noir : http://wawawoom.fr/geocaching/GC84ZZG/step2-998c776d-8d84-4756-b92f-e805a22ac773/998c776d-8d84-4756-b92f-e805a22ac773/black.gif) tous les éléments minéraux (roche, mur, sable), tous les autres éléments devront être en blanc (http://wawawoom.fr/geocaching/GC84ZZG/step2-998c776d-8d84-4756-b92f-e805a22ac773/998c776d-8d84-4756-b92f-e805a22ac773/blackAndWhite.gif).
Une fois le QR code décodé, on obtient le lien suivant : https://bit.ly/2OF5G1p, qui une fois lancé dans le navigateur lance le téléchargement du premier fichier ZIP nommé: « FTFORCE.z01 »

====

2ème partie du ZIP : 
- Il faut résoudre une énigme visible ici : http://wawawoom.fr/geocaching/GC84ZZG/step3-07ba609d-6553-4c27-9a1e-1569c75094d9/
On y voit une animation, ainsi qu’un compteur qui va de 1 à 42. Il faut ici également reconstituer un QR code. Il faut faire 42 captures d’écrans et superposer toutes les copies d’ecrans pour reconstituer le QR Code. Le problème c’est qu’il est difficile d’effectuer toutes les captures car le défilement est très rapide. Pour le ralentir, il suffit de rajouter « ?speed=1000 » ou « ?vitesse=1000 » (ou 1000 est le nombre de millisecondes d’affichage de chaque image) à l’url pour ralentir le défilement. Ensuite les captures d’écran superposées ressemblent à ça: http://wawawoom.fr/geocaching/GC84ZZG/step3-07ba609d-6553-4c27-9a1e-1569c75094d9/83297afb-9f41-4358-921c-0fb2c1107764/QRCode.gif. Une fois le QR code décodé, on obtient le lien suivant : https://bit.ly/2K1eFv7 qui une fois lancé dans le navigateur lance le téléchargement du deuxième fichier ZIP nommé: « FTFORCE.z02 »

====

3ème partie du ZIP : 
Il faut ici aussi trouver un QR code. La musique présente sur cette page est le thème principal du Jeu Zelda, mais si on l’ecoute jusqu’a la fin, on découvre qu’il y a quelquechose d’étrange à la fin de la musique (comme le suggère l’indice sur la page). Ce son bizarre est en fait la représentation audio du QR code. Pour le découvrir il faut regarder le fichier MP3 en mode « spectrogramme ». Le site web https://academo.org/demos/spectrum-analyzer/ permet de faire ce genre d’analyse. En uploadant ce fichier sur ce site on peut voir la fin du fichier : http://wawawoom.fr/geocaching/GC84ZZG/step4-afdccc76-199d-42b6-ab23-c1cd25209d18/2aac9c2e-b9e6-44b4-9b6d-76c82d7fca79/spectrum.gif
Une fois le QR code décodé, on obtient le lien suivant : https://bit.ly/2HTCq6w qui une fois lancé dans le navigateur lance le téléchargement du troisième fichier ZIP nommé: « FTFORCE.zip »

====

3/ Finir la première quête du jeu ZELDA pour obtenir les coordonnées NORD

Maintenant, il faut ouvrir le fichier ZIP, en double cliquant sur le fichier « FTFORCE.z01 », et c’est le moment d’utiliser le Mot de passe récupéré précédemment : « GANON »
Le zip contient 4 fichiers : 

- HELP.jpg (ce fichier contient un lien (http://bit.ly/2DmduRe) qui une fois ouvert, dévoile la 2eme mission.
- EMULATOR-NESTOPIA-MACOS.zip
- EMULATOR-NESTOPIA-WINDOWS.zip
- GC84ZZG - The legend of Zelda.nes

Il faudra ensuite installer le logiciel « NESTOPIA » qui est un émulateur de jeu video de la NES. Puis ensuite utiliser cet émulateur pour ouvrir le fichier « GC84ZZG - The legend of Zelda.nes » qui est une version de Zelda modifiée et qui contient les Coordonnées NORD dans l’écran des crédits une fois la quête 1 terminée. Voir copie d’écran : 
http://wawawoom.fr/geocaching/GC84ZZG/reviewer-b01fb214-aecf-4294-91a1-8134cb43fb7a/NORD.gif

====

4/ Finir la deuxième quête du jeu ZELDA pour obtenir les coordonnées EST

Lorsque l’utilisateur finit la premiere quête, le jeu est automatiquement relancé en mode deuxième quête. Les coordonnées EST sont fournies dans l’écran de crédits après avoir battu le boss final « Ganon », voir copie d’écran : http://wawawoom.fr/geocaching/GC84ZZG/reviewer-b01fb214-aecf-4294-91a1-8134cb43fb7a/EST.gif

====

Les coordonnées finales de la boite sont donc : N43° 48.534 E 007° 14.559
