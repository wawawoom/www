# WuiTitle

Title component with semantic heading levels (h1–h6) and matching visual looks. All looks at a glance:

<Canvas of={WuiTitleStories.All} sourceState="none" />

## Props

`WuiTitle` extends the HTML attributes of heading elements (`h1`–`h6`).
All other props from `HTMLAttributes` (e.g. `id`, `style`, `aria-*`) are supported.

<ArgTypes />

## Design tokens

Visual sizes (`h1`–`h6` looks) come from CSS custom properties in `WuiTitle.css` (e.g. `--wui-title-font-size-h1`), which are generated from `title.font.size` and `title.lineHeight` in `libs/design-token/src/tokens/atomic/font.json` → `variables.css`.

`WuiTitleAs` and `WuiTitleLook` are generated under **`@wawawoom/design-token/enum`** from `title.font.size` in `font.json` (same keys and order as the CSS variables). `WuiTitle.props.ts` re-exports them for convenience.

## Implementation

h1 heading (default):

```tsx
import { WuiTitle, WuiTitleAs, WuiTitleLook } from "@wawawoom/wui";

<WuiTitle as={WuiTitleAs.H1}>Page title</WuiTitle>;
```

h1 heading with a specific look of h3:

```tsx
import { WuiTitle, WuiTitleAs, WuiTitleLook } from "@wawawoom/wui";

<WuiTitle as={WuiTitleAs.H1} look={WuiTitleLook.H3}>
  Section heading
</WuiTitle>;
```
